# xingtu：同一个 prompt，不同 AI 做的星空网站

main 分支只放固定的任务说明 [PROMPT.md](PROMPT.md)。每个 AI 拿到同样的 prompt，在自己的分支上完成，用来对比不同 AI 的效果。

## 分支

| 分支                 | 内容                                                                      |
| -------------------- | ------------------------------------------------------------------------- |
| `main`               | 只有 PROMPT.md 和本说明                                                   |
| `ai/claude-opus-5-5` | Claude（Claude Code 云端会话，模型 claude-opus-5-5），2026-09-26 至 09-27 |

## Claude 分支的轮次 tag

Claude 这一版是多轮对话逐步做出来的，不是一次性按 PROMPT.md 生成的。每轮结束时的状态都打了 tag：

| tag                  | 这一轮的要求                                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `claude-opus-5-5/r1` | 最初的 MVP：HYG v4.1 星表、星点着色器、观测者与时间、地平线、日月行星、亮星标签、网格                                   |
| `claude-opus-5-5/r2` | 六项新功能：AT-HYG 与 HEALPix 分块、自行与光行差、星座（含三垣二十八宿）、HiPS 银河、立体投影、大气 / 信息卡 / URL 分享 |
| `claude-opus-5-5/r3` | 下拉框文字更醒目；增加南半球城市                                                                                        |
| `claude-opus-5-5/r4` | 预设地点只分南北半球；精简中国城市                                                                                      |
| `claude-opus-5-5/r5` | 大气效果加透明度（大气浓度滑块）                                                                                        |
| `claude-opus-5-5/r6` | 去掉“大气”复选框                                                                                                        |

PROMPT.md 把以上各轮的要求合并成了一份。

## 加入一个新的 AI

1. 把 PROMPT.md 的内容原样发给它。
2. 让它从 main 新建分支 `ai/<模型名>`，在上面开发并推送。
3. 在本地并排对比，每个分支一个目录、一个端口：

```bash
git fetch origin
git worktree add ../xingtu-<模型名> ai/<模型名>
cd ../xingtu-<模型名>
pnpm install && pnpm data && pnpm dev --port 5174
```

星表原始数据和生成的二进制文件都不在仓库里，每个分支按自己 README 里的说明生成。
